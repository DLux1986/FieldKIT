📅 Calendar Sync

Export your Outlook / Microsoft 365 calendar as an .ics file and import it here. Existing project links are preserved across syncs.

How to export from Outlook
  1. Open Outlook on the web (outlook.office.com) or the desktop app.
  2. Go to Calendar → Settings → View all Outlook settings → Calendar → Shared calendars.
  3. Under Publish a calendar, select your calendar and set permissions, then copy the ICS link — or export via File → Open & Export → Import/Export → Export to a file → iCalendar (.ics) in the desktop app.
  4. Save the .ics file and select it below.
